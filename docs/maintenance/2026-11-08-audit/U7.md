## Findings

### U7-01 — pyproject.toml Homepage URL points to GitHub, but repo is on Gogs [LOW]

file:line: `pyproject.toml:48-49`

evidence:
```toml
Homepage = "https://github.com/moeshawky/sia-hu"
Repository = "https://github.com/moeshawky/sia-hu"
Issues = "https://github.com/moeshawky/sia-hu/issues"
```

mechanism: The private Gogs setup removed GitHub as the remote. The PyPI
metadata still points to a GitHub URL that may not exist or may be stale.
Impact: misleading package metadata. Fix: update to Gogs URL or remove.

### U7-02 — Coverage config omits `sia` package [LOW]

file:line: `pyproject.toml:108`

evidence:
```toml
source = ["capture_proxy", "model_headroom"]
```

mechanism: The `sia` package (thin dispatcher) is not in the coverage source
list. Since `sia` has no tests and is a pure aliasing layer, this is
arguably correct, but it means `sia` coverage is never measured. Impact:
minor. Fix: add "sia" to the list if tests are added.

### U7-03 — mypy overrides missing for `transformers` and `torch` [INFO]

file:line: `pyproject.toml:95-101`

evidence:
```toml
[[tool.mypy.overrides]]
module = "accelerate"
ignore_missing_imports = true

[[tool.mypy.overrides]]
module = "gguf"
ignore_missing_imports = true
```

mechanism: `transformers` and `torch` are used but not in the overrides list.
They happen to have type stubs installed, so mypy passes. But if they're
missing (e.g., in a minimal env), mypy would fail. Impact: latent fragility.
Fix: add overrides for `transformers.*` and `torch.*`.

### U7-04 — `requires-python = ">=3.12"` but `.python-version` says 3.14 [INFO]

file:line: `pyproject.toml:13`

evidence:
```toml
requires-python = ">=3.12"
```

mechanism: The repo uses Python 3.13/3.14 at runtime (per capture-proxy
AGENTS.md: "Python 3.14 runtime"). The `requires-python` floor of 3.12 is
conservative but may allow installation on 3.12 where some features (e.g.,
`X | Y` type syntax in 3.10+) work but newer stdlib features don't. Impact:
potential install on unsupported Python. Fix: bump to `>=3.13` to match
runtime, or document 3.12 as minimum tested.

### U7-05 — CI triggers only on `main`, not `public-repo` [MEDIUM]

file:line: `.github/workflows/ci.yml:4-7`

evidence:
```yaml
on:
  push:
    branches: [main]
  pull_request:
    branches: [main]
```

mechanism: The operator's working branch is `public-repo` (per AGENTS.md).
Pushes to `public-repo` do NOT trigger CI. The last CI run status is
unverified (per 2026-11-06 handoff). Impact: no automated verification on
the branch that carries the actual work. Fix: add `public-repo` to the
branch list, or change the default branch.

### U7-06 — CI does not install `transformers`/`torch` extras explicitly [LOW]

file:line: `.github/workflows/ci.yml:16`

evidence:
```yaml
run: uv sync --extra dev --extra headroom --extra gguf
```

mechanism: `--extra headroom` includes `transformers>=5.22.1` and
`torch>=2.15`. The `--extra gguf` adds `gguf>=0.19`. This is correct for
the full test suite. But the refusal tests that need transformers will skip
if the extra isn't installed. Since `--extra headroom` includes it, this is
fine. However, the CI matrix tests Python 3.12 and 3.13; `torch>=2.15` may
not have wheels for 3.12 on all platforms. Impact: potential CI failure on
3.12. Fix: verify torch wheel availability for 3.12.

### U7-07 — publish.yml has no test gate before publishing [MEDIUM]

file:line: `.github/workflows/publish.yml:1-25`

evidence:
```yaml
on:
  release:
    types: [published]
...
steps:
  - uses: actions/checkout@v4
  - uses: astral-sh/setup-uv@v5
  - name: Build
    run: uv build
  - name: Check distribution
    run: uv run --with twine twine check dist/*
  - name: Publish
    run: uv publish
```

mechanism: The publish workflow builds and publishes without running the
verify chain (lint, format, typecheck, tests). A broken release could be
published. Impact: release quality gate missing. Fix: add a test job or
require CI to pass before release.

### U7-08 — AGENTS.md lists 15 "authorized dispatch targets" that don't exist [MEDIUM]

file:line: `AGENTS.md:644-672`

evidence: The table lists `architect`, `chronicler`, `mh-annotation-writer`,
`mh-annotation-reviewer`, `mh-annotation-validator`, `mh-designer`,
`mh-documentarian`, `mh-junior-engineer`, `mh-precision`, `mh-reviewer`,
`mh-worker`, `reviewer`, `scout`, `surgeon`, `worker`. But `.opencode/agents/`
contains only 7 files: `sia-contract-guardian`, `sia-designer`,
`sia-documentarian`, `sia-junior-engineer`, `sia-precision`, `sia-reviewer`,
`sia-worker`.

mechanism: The dispatch-target table was written for a different agent set
(pre-unification or aspirational). An agent following this gate would try to
dispatch to non-existent agents. Impact: broken dispatch protocol. Fix:
rewrite the table to match the 7 actual agents, or create the 15 missing
agent definitions.
