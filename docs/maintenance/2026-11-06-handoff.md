## Findings, ranked

Severities are the auditors'. None has been adjudicated by AD or proven; treat all as candidates
until the next session re-derives them. Every one carries a file:line in its report.

### Contract divergences (highest value — documentation and behavior disagree)

- **U3-01 / U5-01 (same defect, found independently) — dense models are scored as if they had
  MoE signals.** `orchestrator.py:465-501` sends dense models down a path that returns
  `status="single_expert"`; `scoring.py:41-49` maps `single_expert` to **0.5 and keeps its
  weight** (only `not_applicable` is skipped, `scoring.py:123-124`). Result: `load_balance` +
  `specialization` (0.20 of total weight) contribute a fixed 0.5, capping a dense model's
  composite at ~0.90. AGENTS.md and `docs/model-headroom/README.md` both state dense models mark
  these **`not_applicable` and weights renormalize**. Verified in source this session: the code
  and the documented contract genuinely disagree. **Decide which one is authoritative** — this is
  a scoring-semantics decision for the operator, not a mechanical patch.
- **U3-04** — `not_applicable` is defined but never emitted; the `_score_signal` branch for it at
  `scoring.py:42-43` is dead code, and both callers `continue` before reaching it.
- **U4-03** — `loader.py:186 detect_architecture()` has no classifier branch; BERT / DeBERTa /
  ModernBERT / laya / RockAndEgg fall through to `"dense"`. DeBERTa remains a recorded UNKNOWN.
- **U2a-02** — `schema.py` classifies 35 of 36 `CaptureRecord` fields; `attempt_number`
  (`models.py:300`) is in none of the three tri-state lists, breaking the null-vs-absent
  invariant that AGENTS.md §7d sells.

### Known defects, re-derived (both previously deferred — do not defer a third time)

- **U4-01 / U4-12 — `[gguf]`-less collection is broken.** `gguf_loader.py:20` imports
  `gguf.constants` at module level with no guard; `ternary_sampling.py:16-19` imports
  `gguf_loader`. `test_gguf_loader.py:11`, `test_gguf_loader_extra.py:7`,
  `test_gguf_loader_legacy.py:9` import it at top level, and `requires_gguf` marks only
  individual functions. Verified by direct read this session. So without the extra, pytest
  **errors at collection** — it does not skip. AGENTS.md's claim that "the GGUF tests skip
  cleanly" is false. CI is unaffected because `ci.yml` installs `--extra gguf`; developers are
  affected. Cheap fix, high papercut cost.
- **U4-02 / U4-13 — `ImportError` missing from except tuples.** `ternary_quants.py:291` and
  `gguf_loader.py:785,887` catch `(AttributeError, NotImplementedError)` /
  `(NotImplementedError, ValueError, TypeError)` but not `ImportError`, which is the exception a
  missing `gguf` actually raises. No test covers the uncaught path — the `gguf`-delegation tests
  are `@requires_gguf`-skipped.

### Silent failures (the operator is told nothing)

- **U3-03 — `--gradient-diagnostics` failures vanish.** `orchestrator.py:624-625` wraps them in
  `except Exception: pass`. Explicitly requested diagnostics silently produce nothing, no warning.
- **U3-02 — human report hides the error cause.** The orchestrator stores the message on
  `signal.error_message`, `human_report.py:24-25` reads it from `signal.data`, so the operator
  sees `[ERROR — no data]` instead of the reason.
- **U2a-01 — sidecar write failure is silent.** Disk/permission failure yields a capture with no
  sidecar, no warning, no `errors/` row (`headroom.py:946-947, 967-971, 1431-1432`). Documented
  as intended (R-09) but still a silent mode; either document it explicitly or emit an error row.

### Numeric / scoring edges

- **U5-02** — NaN in activations is never counted dead (`dead_neurons.py:21-26,32-39`);
  `dead_fraction` undercounts and the NaN reaches the composite.
- **U5-04** — `growth_factor.py:128-129`: `math.log(0)` on zero `model_params`/`measured_loss` is
  caught by a broad except and scored 0.0, conflating invalid input with a computation failure.
- **U5-05** — `growth_factor` alpha is unbounded but silently clamped to [0,1] in scoring
  (`scoring.py:60-62`), losing extreme-regime signal.
- **U5-03** — empty `grad_weight_ratio` list scores 0.5 neutral, indistinguishable from skipped.
- **U1b1-03** — `usage_normalized.context_total` is computed unclamped and can exceed real context.

### Carrier robustness

- **U2b-02 — `--stop` can kill an unrelated process.** `__main__.py:463-482` sends SIGTERM to
  whatever PID the pid file holds, with no ownership/cmdline check. `--daemon` guards against
  live-PID reuse (`538-541`); `--stop` does not. PID reuse is a real hazard on a long-lived box.
- **U2b-01 — blob dedupe race.** `blobs.py:161-165` is check-then-`write_bytes` with no
  temp+rename; concurrent identical requests can tear a blob.
- **U1a2-02 — unbounded runtime refresh.** `app.py:2572-2593` spawns concurrent refresh work with
  no lock or dedup on upstream failure.
- **U1a2-03 — usage zeros.** `app.py:2722-2740` turns missing/null upstream usage into silent
  zeros, which corrupts the `context_total` aggregates AGENTS.md §7b tells operators to compute.
- **U1a1-03 — `/v1/models` misattributes proxy bugs.** `app.py:673` broad `except` reports any
  failure as a connection error.
- **U1a1-01** — `upstream.py` connect/read failures propagate uncaught.
- **U1a1-02** — ollama translation crashes on non-dict upstream JSON, misattributed as 502.
- **U1b2-01** — whitespace-only `x-session-id` passes verbatim while `x-user-id` rejects blank.
- **U1b2-02** — user bucket digest truncated to 64 bits; distinct Authorization keys collide.
- **U1b1-01** — a client-disconnected stream is stored as `response_body` with no in-body
  completeness marker. Honesty exists only in `terminal.classification` /
  `stream_diagnostics.done_seen` / `client_disconnected`. A consumer reading only
  `response_body` can mistake a prefix for a complete answer.
- **U1a2-01** — rerank ollama 501 is never logged to `errors/`, unlike other failure paths.
- **U1a2-04** — malformed SSE chunks silently dropped, duplicates concatenated in the stored body.
- **U1a2-05** — `downstream_exception` (`app.py:2081`) is declared but never assigned, always None.
- **U2b-03** — `logger.py:252` docstring claims no `..` sequence, but `.` is in the safe charset
  so the id `".."` yields `..-hash.jsonl`. Not traversal; the doc overclaims.
